# Концепты профильного README

Основная страница профиля не изменена. Ниже — пять самостоятельных вариантов с одинаковым позиционированием и разной визуальной подачей.

| Вариант | Характер | Главная фишка |
|---|---|---|
| [01 — Arcade Snake](./01-arcade-snake/README.md) | Яркий, игровой | Анимированная змейка съедает contribution graph |
| [02 — Cyber Terminal](./02-cyber-terminal/README.md) | Технологичный, дерзкий | Терминальный hero-блок, неон и typing-анимация |
| [03 — AI Constellation](./03-ai-constellation/README.md) | Футуристичный | Анимированная карта «1С × AI × инструменты» |
| [04 — Clean Premium](./04-clean-premium/README.md) | Статусный, спокойный | Минимум шума, максимум архитектурного веса |
| [05 — Dev Dashboard](./05-dev-dashboard/README.md) | Инженерный, насыщенный | Живые GitHub-метрики и dashboard-композиция |

> Все внешние виджеты используются только в этих макетах. Перед переносом выбранного варианта в профиль можно оставить наиболее стабильные и убрать лишние.
