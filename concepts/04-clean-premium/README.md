### Главная идея

Последние 16+ лет я проектирую и запускаю системы на платформе 1С. Сейчас мой основной интерес — соединить зрелую enterprise-разработку с AI-агентами, быстрыми инструментами и современным инженерным опытом.

### Избранные работы

#### [1c-mcp](https://github.com/Untru/1c-mcp) · карта AI-экосистемы для 1С

Каталог MCP-серверов, сценариев и архитектурных паттернов: метаданные, справка платформы, тестирование, code review, IDE и работа с живыми базами.

#### [ibcmd-rs](https://github.com/Untru/ibcmd-rs) · исследование новых инструментов платформы

Автономный Rust-конвертер для работы с конфигурациями 1С. Проект на пересечении reverse engineering, производительности и безопасной инженерии.

#### [GitManager](https://github.com/Untru/gitmanager) · Git workflow без барьера входа

Управление задачами и ветками, сборка и разборка конфигураций — в интерфейсе, понятном 1С-разработчику.
